DEMO BASE - GESTIÓN DE MESAS EN RESTAURANTES

1. Crear la base de datos:
   - Abrir MySQL Workbench o consola MySQL.
   - Ejecutar el archivo database.sql.

2. Configurar credenciales:
   - Abrir app.py.
   - Cambiar en DB_CONFIG si tu usuario o contraseña son diferentes.

3. Instalar dependencias:
   pip install -r requirements.txt

4. Ejecutar:
   python app.py

5. Abrir en el navegador:
   http://127.0.0.1:5000/

Páginas:
- /           Vista cliente
- /admin      Panel administrativo
